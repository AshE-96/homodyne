## ۴. تمرین

```bash
cd parts/03-standalone/hmd-s04-ai-hurricane-forecast
python3 -I artifact/storm_live.py --selftest
```

باید با `selftest ok` تمام شود (حدود ۵ ثانیه، بی‌شبکه؛ اگر node نصب نباشد، یک چک «skip» می‌شود).

```bash
python3 -I artifact/storm_live.py --serve
```

بعد در Chrome: `http://127.0.0.1:8766/storm_live.html` (بی‌سرور هم کار می‌کند: `artifact/storm_live.html` را مستقیم باز کن).

**کلیدها:** `1` `2` `3` نماها · `← →` زمان شروع قبلی/بعدی · `[ ]` طوفان قبلی/بعدی · `C` مخروط (OFCL ← GDMI ← خاموش) · `K` مسیر/شدت · `B` حلقه‌های عدد چاپی NHC · `S` نمونهٔ جدول NHC / نمونهٔ مدل‌های انتخابی · `G` (نمای ۳) گونو/شاهین/هر دو · `H` پنهان‌کردن کنترل‌ها.

| قاب | URL | کار |
|---|---|---|
| ۲ | `?view=arabian&ni=gonu&clean=1` | `G` ← شاهین، `G` ← هر دو |
| ۴ | `?view=replay&storm=AL13&init=2025102500&m=OFCL,GDMI,EMXI,AVNI&cone=0` | مکث روی ستون ۷۲ ساعت پنل |
| ۵ | همان، بعد `C` | مخروط دور OFCL |
| ۸ | `?view=errors&kind=track&sample=nhc&nhc=1&m=OFCL,GDMI,EMXI,AVNI,HFAI,HCCA` | حلقه‌های NHC روی نقطه‌ها |
| ۹ | همان | اشاره به ردیف ۷۲ ساعت پنل «GDMI − OFCL» |
| ۱۰ | همان، بعد `K` | شدت |
