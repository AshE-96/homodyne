## ۴. تمرین

```bash
cd parts/03-standalone/hmd-s03-alphafold-iranian-diseases
python3 -I artifact/fold_live.py --selftest   # بی‌شبکه؛ باید «selftest ok» بدهد
python3 -I artifact/fold_live.py --serve      # http://127.0.0.1:8766/fold_live.html
python3 -I artifact/fold_live.py --fetch      # فقط اگر خواستی داده را تازه کنی (شبکه لازم)
```

- [ ] **mock (بی‌شبکه):** `--selftest` سبز؛ `artifact/fold_live.html` را مستقیم در Chrome باز کن؛ همه‌چیز جز دکمهٔ L کار می‌کند.
- [ ] **اجرای واقعی:** `--serve`، بعد کلید L: «AlphaFold DB, live … same model as our cached copy ✓». اگر نوشت «changed»، اول `--fetch`، بعد `--selftest`، بعد عددهای قاب ۸ و ۱۰ تا ۱۱ را با `artifact/derived/SOURCE.txt` تطبیق بده.
- [ ] **replay:** اگر روز ضبط شبکه نبود، همان صفحهٔ بی‌شبکه را نشان بده و بگو «دادهٔ ۷ آذر». هرگز آن را «زنده» نخوان.
- [ ] تمرین کامل با صدای بلند و زمان‌سنج: هدف حدود ۱۲:۱۰.
- [ ] خودآزمایی `study-fa.md`: همهٔ پاسخ‌ها بی‌نگاه.

### حالت‌های دمو برای هر قاب (URL ثابت؛ پیش از ضبط H بزن)
