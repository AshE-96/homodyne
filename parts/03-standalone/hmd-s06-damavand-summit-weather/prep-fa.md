## ۴. تمرین

از پوشهٔ قسمت:

```bash
cd parts/03-standalone/hmd-s06-damavand-summit-weather
```

```bash
python3 -I artifact/summit_live.py --selftest
```

باید با `selftest ok` تمام شود (حدود ۵ ثانیه، بی‌شبکه).

```bash
python3 -I artifact/summit_live.py --replay derived/replay-2026-11-28.json --serve
```

بعد `http://127.0.0.1:8766/summit_live.html`. (بدون سرور هم کار می‌کند: فایل را مستقیم باز کن.) اجرای زنده (روز ضبط، ۵ دقیقه پیش‌تر):

```bash
python3 -I artifact/summit_live.py --serve
```

یا با Open-Meteo، اگر محمد اجازه داد: `--openmeteo`. بی‌شبکه از آخرین اجرا: `--offline`.

**کلیدها:** `1`–`4` نماها · `← →` زمان (در نمای ۲: مرحله) · `, .` زمان در نمای ۲ · `S` قله/بارگاه سوم · `M` مدل بعدی در نمای ۲ · `H` پنهان.

- [ ] `--selftest` بی‌شبکه اجرا شد.
- [ ] replay ۲۸ نوامبر باز شد و چهار نما با `cheatsheet-fa.md` خواند.
- [ ] اجرای زندهٔ روز ضبط؛ خروجی `derived/latest.json` به `artifact/runs/<تاریخ>/` کپی شد.
- [ ] تمرین کامل با صدای بلند: هدف حدود ۱۲ دقیقه.
- [ ] خودآزمایی `study-fa.md`: همهٔ پاسخ‌ها بی‌نگاه.
