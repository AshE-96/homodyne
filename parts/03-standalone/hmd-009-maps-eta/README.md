# HMD-009 · Algorithm X-Ray · v5

## گوگل‌مپس از کجا می‌فهمد کی می‌رسی؟

**وضعیت:** متن، دک، بستهٔ انتشار و شبیه‌سازی آماده؛ شبیه‌سازی اجرا شده (ILLUSTRATIVE). منبع R15 ۷ نوامبر ۲۰۲۶ بازبینی شد. هیچ اجرای بازی نمانده.
**قالب:** Algorithm X-Ray · **زنجیره:** HMD-008 (جواب‌نامهٔ غلط) ← **HMD-009** → HMD-010 (نمرهٔ منفی)
**زمان:** حدود ۱۴ تا ۱۵ دقیقه · ۱۶۶۸ واژهٔ گفتاری · ۱۴ قاب · هوک: Shock/Contradiction

**جملهٔ مرکزی:** ETA اندازه‌گیریِ ترافیکِ الان نیست، پیش‌بینیِ ترافیکی است که وقتی به هر خیابان برسی وجود خواهد داشت؛ و طبق توضیح منتشرشدهٔ گوگل/DeepMind (۲۰۲۰)، تکهٔ مهم این پیش‌بینی گوش‌دادن هر تکه خیابان به همسایه‌هایش است.

**مرز ادعا:** این ماکت الگوریتم خصوصی و فعلی Google Maps یا ترافیک تهران را بازتولید نمی‌کند؛ ترافیک ساختگی است و دنیا را خودمان طوری ساختیم که همسایه‌ها مهم باشند.
