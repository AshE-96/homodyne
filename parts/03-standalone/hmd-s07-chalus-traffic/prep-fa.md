**از فایل خام تا صفحه (از پوشهٔ قسمت):**

```bash
cd parts/03-standalone/hmd-s07-chalus-traffic
python3 -I artifact/chalus_prep.py --inspect artifact/data/raw/*
```

خروجی می‌گوید کدام ستون‌ها شناخته شد («recognised»)، کدام نه («not used»)، و سه سطر نمونه. ساعتی که دستگاه کمتر از ۴۵ دقیقه کار کرده شمار ندارد (نه «خلوت»)؛ سطرهای تکراریِ دو دانلودِ هم‌پوشان یک بار شمرده می‌شوند؛ اگر برچسب ساعت ۱ تا ۲۴ است (پایان ساعت)، همه‌چیز یک ساعت جابه‌جا می‌شود: با نمونه‌ها چک کن. اگر ستون شمار یا زمان شناخته نشد:

```bash
python3 -I artifact/chalus_prep.py --map '{"total": "نام دقیق ستون", "start": "نام ستون زمان"}' --inspect artifact/data/raw/*
```

اگر فایل ستون کد ندارد، جهت را کنار نام فایل بگو: `raw/a.xlsx=N raw/b.xlsx=S`. فایل `.xls` قدیمی یا `.rar`: اول باز کن و `.xlsx` ذخیره کن. وقتی درست بود، بی `--inspect`:

```bash
python3 -I artifact/chalus_prep.py --only کدِN,کدِS artifact/data/raw/*   # --only فقط اگر فایل چند ترددشمار دارد
python3 -I artifact/chalus_live.py --data artifact/data/chalus_hourly.csv
```

نتیجه: `artifact/data/chalus_live_real.html` (صفحهٔ واقعی، **بی** واترمارک) و `artifact/data/results-real.json` (جدول مسابقه). هر دو git-ignored. خط آخر `chalus_prep` می‌گوید چند ساعت بسته (از اطلاعیه‌ها و از قاعدهٔ سرانگشتی)، چند ساعت بی‌شمار و چند ساعت «برآوردشده» دارد؛ این‌ها را در `sources.md` R01 بنویس.

**پس از اجرای واقعی:**
