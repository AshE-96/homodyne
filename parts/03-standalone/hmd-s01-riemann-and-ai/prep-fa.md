## ۲. دمو

از پوشهٔ قسمت:

```bash
cd parts/03-standalone/hmd-s01-riemann-and-ai
```

```bash
python3 -I artifact/zeta_live.py --selftest
```

باید با `selftest ok` تمام شود (حدود ۳ ثانیه؛ اگر mpmath نصب نبود، سه چک آخر «skip» می‌شود و اشکالی ندارد).

```bash
python3 -I artifact/zeta_live.py --serve
```

بعد در Chrome: `http://127.0.0.1:8765/zeta_live.html`. (بدون سرور هم کار می‌کند: فایل `artifact/zeta_live.html` را مستقیم باز کن.)

**کلیدها:** `1` `2` `3` نماها · `→ ←` یک قدم · `↑ ↓` دو برابر/نصف · `Space` پخش · `X` بازهٔ x (۳۰، ۱۰۰، ۴۰۰، ۱۰۰۰) · `0` صفر صفر · `H` پنهان‌کردن کنترل‌ها و نوار کلیدها.
**حالت ثابت با URL:** `?view=a&k=10&x=100` · `?view=b&T=50` · `?view=c&year=7`.

**سه بار تمرین کن (هر بار حدود ۵ دقیقه):**
| تمرین | چه چیزی | نکته |
|---|---|---|
| الف | قاب ۵: k = ۰ ← ۱ ← ۲ ← ۳ ← ۶ ← ۱۲ ← Space ← توقف حدود ۲۰۰ | مکث برای حدس قبل از «دوازده تا». سرعت Space از k = ۵۰ به بعد زیاد می‌شود؛ حدود ۱۲ ثانیه تا ۲۰۰. |
| ب | قاب ۶: T = ۵۰ ← ۱۰۰ | عدد ۲۹ و «formula θ(T)/π + 1 = 29.00» را با چشم دنبال کن. |
| ج | قاب ۷ و ۸: سال‌ها با → | روی ۲۰۲۰ مکث، سؤال حدسی، بعد دو بار →. ردیف هاشورخوردهٔ ۱۹۷۳ را با «فقط به شرط درستی فرضیه» بگو. |

**ضبط صفحه:** Chrome تمام‌صفحه (`F11` یا ⌃⌘F)، پنجره ۱۹۲۰×۱۰۸۰ یا ۱۶۰۰×۹۰۰، `H` زده‌شده، نشانگر ماوس بیرون از قاب. QuickTime ← New Screen Recording.

## ۳. اختیاری: لحظهٔ Lean (قاب ۱۰، حدود ۲۰ ثانیه)

> هیچ‌چیز روی این Mac نصب نشده. اگر وقت نداری، کارت قاب ۱۰ دک کافی است.

1. نصب elan (مدیر نسخهٔ Lean) طبق صفحهٔ رسمی: https://lean-lang.org/install/ (یا افزونهٔ «Lean 4» در VS Code که elan را خودش نصب می‌کند).
2. یک پروژهٔ تازه با Mathlib (دانلود چند گیگابایت cache؛ ۱۵ تا ۴۰ دقیقه):

```bash
lake +leanprover-community/mathlib4:lean-toolchain new hmd_lean math
```

3. محتوای `artifact/lean/Moment.lean` را در `HmdLean/Basic.lean` بگذار، بعد:

```bash
cd hmd_lean && lake exe cache get && lake build
```

4. باید ببینی: خط ζ(2) بی‌صدا می‌گذرد؛ روی خط دوم هشدار `declaration uses 'sorry'`. همین هشدار را در VS Code بزرگ‌نمایی کن و ضبط کن.
5. اگر نام `riemannZeta_two` یا `RiemannHypothesis` در نسخهٔ Mathlib تو فرق داشت، در مستندات Mathlib جست‌وجو کن و فقط نام را درست کن (معنای گزاره را عوض نکن).
6. **اختیاری‌تر:** ساختن خود مخزن `anthropics/zeta-23-lean` (پوشهٔ `zeta23`، toolchain v4.33.0-rc2) ساعت‌ها طول می‌کشد؛ برای ویدیو لازم نیست.
