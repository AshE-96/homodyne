Every critical fact, a random sample, and every disagreement that matters.

What v1.0 supports, and what it does not

This result can support

  • Choosing a tool to pilot for first-pass market research
  • Knowing which failure modes to watch for in that work
  • Comparing against a real manual baseline
  • A scenario-based recommendation with stated trade-offs

This result does not prove

  • That one tool is best for all research
  • Anything about Persian or other non-English output
  • Anything about the underlying base models
  • Anything about versions released after the run window

Rerun plan: the tools will change, so v1.0 has an expiry. The dataset card, frozen protocol, run evidence and analysis notebook all ship together — so the next run can be compared to this one instead of replacing it silently.
