04 / 16 · 02:29 · RECOMPUTE ≠ RERUN
RECOMPUTEsame

Same labelled answers + same code → the same number, exactly. Like re-adding a restaurant bill.

RERUNmay differ

Ask the model again → answers may change (sampling, silent version updates). Like ordering the dish again tomorrow.
