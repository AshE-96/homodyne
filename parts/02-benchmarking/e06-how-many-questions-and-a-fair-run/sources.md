## محاسبه‌های خودمان (`artifact/power_lab.py`، اجرا ۷ نوامبر ۲۰۲۶، seed 12، ۲۰۰۰ اجرای شبیه‌سازی برای هر خانه) — ILLUSTRATIVE

- **مدل داده:** برای هر سؤال تفاضل جفتی d ∈ {+1, 0, −1}؛ p₁₀ = (r + Δ)/2، p₀₁ = (r − Δ)/2 که r نرخ اختلاف دو مدل است. SD(d) = √(r − Δ²). MDE = (1.96 + 0.84) · SD / √n_eff. α = 0.05 دوطرفه، توان ۰٫۸۰.
- **بخش ۱ (بازسازی Card پیوست C):** n = 500 ⇒ توان تحلیلی ۲۹٪، شبیه‌سازی با McNemar دقیق ۲۴٪، بزرگ‌نمایی ×1.9؛ n = 2000 ⇒ ۸۱٪ / ۷۸٪، ×1.1. (مقاله: حدود ۰٫۲۵ و ×1.9؛ «نزدیک ۸۰٪» و ×1.1.)
- **بخش ۲ (جدول MDE، اختلاف ۱۰٪):** ۱۰۰ سؤال 8.9؛ ۲۵۰ 5.6؛ ۵۰۰ 4.0؛ ۱۰۰۰ 2.8؛ ۲۰۰۰ 2.0؛ ۴۰۰۰ 1.4 امتیاز. بازسازی Miller: 969.
- **بخش ۳:** ۵۰۰ سؤال، A ۷۲٪ و B ۷۰٪، اختلاف ۱۰٪ ⇒ MDE غیرجفتی 8.0 و جفتی 4.0 امتیاز. Miller با فرمول خودش: K=1 ⇒ 13.3٪ (مقاله ۱۳٫۲٪، گرد کردن)، K=10 ⇒ 7.6٪ (مقاله ۷٫۵٪)، K=∞ ⇒ 6.6٪ (سقف؛ فقط از artifact).
- **بخش ۴ (همبستگی درون‌گروهی ICC = 0.5، فرضی):** ۱۰۰۰ ردیف به شکل ۱۰۰۰×۱ / ۲۵۰×۴ / ۵۰×۲۰ ⇒ اثر طرح 1.0 / 2.5 / 10.5؛ n مؤثر 1000 / 400 / 95. بدون فرق واقعی: «برندهٔ» آزمون ساده 4.7٪ / 23.1٪ / 52.8٪؛ آزمون خوشه‌ای 4.7٪ / 5.5٪ / 5.3٪. با فرق واقعی ۳ امتیاز، توان آزمون خوشه‌ای 86.2٪ / 50.6٪ / 17.5٪. با seed 11: 5.3/21.5/54.8 و 84.0/47.1/17.5 (همان الگو).
- **بخش ۵:** ۶ مدل ⇒ ۱۵ جفت؛ اگر همه مستقل و بدون فرق: 1 − 0.95¹⁵ = 53.7٪ (در گفتار «بیشتر از نصف»؛ جفت‌ها مستقل نیستند، فقط مرتبهٔ بزرگی).
- `--selftest`: ۱۶ بررسی، همه ok (`artifact/selftest-output.txt`).
