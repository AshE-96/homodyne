# HMD-010 · Benchmark E05 · v5

## نمرهٔ منفی می‌تواند AI را محتاط‌تر کند؟

**وضعیت:** آمادهٔ ضبط. قاب ۱۱ با کارت NOT RUN YET (اجرای واقعی در ویدیوی پیگیری). منبع‌ها ۷ نوامبر ۲۰۲۶ بازبینی شدند؛ دفترچهٔ کنکور را یک بار در مرورگر خودت ببین.
**قالب:** Benchmark Lab · **زنجیره:** HMD-009 (گوگل‌مپس) ← **HMD-010** → HMD-011 (پیش‌بینی هوا)
**زمان:** حدود ۱۴ دقیقه · واژهٔ گفتاری: ببین `make episodes` · ۱۵ قاب · هوک: Story-Open (کنکور)

**جملهٔ مرکزی:** نمرهٔ منفی یک «خط سکوت» می‌سازد (t = k/(k+1))؛ ولی فقط وقتی AI را محتاط‌تر می‌کند که مدل با شنیدن قانون واقعاً جواب‌هایش را عوض کند و اطمینانش هم صادق باشد.

**مرز ادعا:** تغییر امتیاز پاسخ‌های ثابت معادل تغییر رفتار تحت دستور تازه نیست؛ پاسخ‌دهنده‌های شبیه‌سازی‌شده مدل زبانی نیستند؛ اثر گفتن قانون به مدل واقعی تا اجرای پیگیری نامعلوم است.
