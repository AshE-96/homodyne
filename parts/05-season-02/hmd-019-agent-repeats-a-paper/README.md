# HMD-019 · Benchmark Lab · فصل ۲، موج ۱

## مقاله را به ایجنت AI دادیم؛ می‌تواند آزمایشش را تکرار کند؟

**وضعیت:** متن، هوک‌ها، بستهٔ انتشار، دک فارسی و انگلیسی، منبع‌ها و artifact آماده‌اند. **نیازمند اجرا [RUN]:** قاب ۹ تا ۱۲ تا وقتی مالک `run` را با کلید خودش اجرا نکرده، `NOT RUN YET` دارند. selftest بدون کلید در ۱۳ نوامبر ۲۰۲۶ گذشت (`artifact/selftest-output.txt`). منبع‌ها همان روز بازبینی شدند.
**قالب:** Benchmark Lab · **انتشار:** ۱ آوریل ۲۰۲۷ (۱۲ فروردین ۱۴۰۶) · **زمان برآوردی:** حدود ۱۳٫۵ دقیقه · **واژهٔ گفتاری:** ۱۵۸۹ (با جای‌خالی‌ها) · **قاب:** ۱۵
**هوک:** Story-Open (قفل‌شده در manifest) — «پنجشنبه شب. یه پوشهٔ خالی، یه مقالهٔ یه‌صفحه‌ای…»

**جملهٔ مرکزی:** یک بار درست انجام‌دادن، دمو است؛ اعتماد یعنی «هر بار» درست، و ایستادن به‌جا وقتی چیزی خراب است. پس برای هر قدم ایجنت جدا تصمیم می‌گیریم: خودکار، با تأیید، یا توقف اجباری.

**مرز ادعا:** همه‌چیز در جعبهٔ آزمایشی و روی سه مقالهٔ یک‌صفحه‌ای با جواب معلوم؛ تکرار یک سناریو نمونهٔ مستقل تازه نیست (نمونه = ۴۵ سناریو)؛ نرخ موفقیت این آزمایش کوچک، اعتمادپذیری در محصول واقعی را تضمین نمی‌کند؛ یک مدل، یک تنظیم، یک تاریخ.

**زنجیره:** HMD-018 (E09: «امروز یه عدد رو از روی فایل‌ها دوباره حساب کردیم… قسمت بعد: مقاله رو به AI دادیم») ← **HMD-019** ← HMD-020 («چرا JSON معتبر لزوماً یعنی خروجی درست نیست؟»؛ پل: هر جواب ایجنت یک فرم مرتب بود و ما فقط با جواب‌نامه وارسی‌اش کردیم؛ بیرون آزمایشگاه جواب‌نامه نیست).
- قاب ۲ تیزر HMD-018 را با همان تصویر رستوران ادامه می‌دهد: فاکتور (recompute) ← سفارش فردا (rerun) ← شاگرد آشپز در آشپزخانهٔ خالی (rebuild).
- قاب ۴ سه مقاله را از HMD-002، HMD-006 و HMD-010 می‌سازد؛ قاب ۱۲ از درس E08 («قانون را پیش از دیدن داده قفل کن») استفاده می‌کند.

## اجرا (از ریشهٔ مخزن)

```bash
A=parts/05-season-02/hmd-019-agent-repeats-a-paper/artifact
python3 $A/agent_lab.py --selftest                    # بدون حساب پولی و بدون کلید، حدود ۳۰ ثانیه
# یک بار: Docker Desktop را روشن کن و  docker pull python:3.11-slim
# کلید: ANTHROPIC_API_KEY=... در private/keys.env (export نکن؛ tools/llm.py خودش می‌خواند)
python3 $A/agent_lab.py plan                          # وضعیت Docker و پروب (key_leak باید blocked باشد)
python3 tools/llm.py check
python3 $A/agent_lab.py run --limit 5 --repeats 1     # پایلوت ارزان
python3 $A/agent_lab.py run --repeats 3               # ۴۵ سناریو × ۳ = ۱۳۵ اجرا؛ پیش از خرج پول می‌پرسد
python3 $A/agent_lab.py report                        # جدول + جمله‌های فارسی قاب ۹ تا ۱۲
```

`run` چه می‌سازد: `artifact/runs/<تاریخ>-<provider>-<model>/` با `meta.json`، `episodes.jsonl`، `transcripts/` (کل گفت‌وگوی هر اجرا)، `cache/` و بعد از `report`، `report.txt`. سقف تماس‌ها: ۱۳۵ × ۱۲ = ۱۶۲۰؛ در selftest، ایجنت ساختگی به‌طور میانگین حدود ۵ تماس در هر اجرا داشت. هزینهٔ واقعی را پایلوت نشان می‌دهد.

## ریسک‌های باز

- **ایمنی:** کد مدل روی ماشین مالک اجرا می‌شود. پیش‌فرض Docker است (بدون شبکه، فقط پوشهٔ کار، بی‌کلید)؛ مسیر Docker روی این مک آزموده نشد چون daemon خاموش بود، پس پروب Docker باید پیش از `run` یک بار سبز شود. `sandbox-exec` فقط با `--i-accept-key-exposure` و ضعیف‌تر است: محیط پردازش‌های دیگر کاربر را می‌خواند (پروب نشانش می‌دهد). خروجی‌ها از کلید پاک می‌شوند. امن‌ترین: Docker، یا کاربر جدا یا ماشین مجازی.
- **کش و تکرار:** تکرارها با پوشهٔ کش جدا مستقل‌اند؛ ولی اگر ارائه‌دهنده دمای پیش‌فرض را پایین بگذارد، تکرارها شبیه‌تر می‌شوند. دما در `tools/llm.py` تنظیم نمی‌شود؛ در `meta.json` مدل و effort ثبت می‌شوند.
- **نمونهٔ کوچک:** ۴۵ سناریو، ۹ سؤال اصلی؛ هر درصد را با این مخرج گفت.
- **پل HMD-020:** اگر اجرای واقعی هیچ «فرم مرتب با عدد غلط» نداشت، تیزر همان‌طور که نوشته شده درست است (دربارهٔ نبودِ جواب‌نامه بیرون آزمایشگاه)، نه دربارهٔ چیزی که دیدیم.
