## فرمول هر قسمت

**سؤال آشنا ← آزمایش دیدنی ← یک تصمیم محصولی.**
بینندهٔ عادی برای سؤال می‌آید و با یک ابزار یا قانون سرانگشتی می‌رود. تخصص مدیر محصول AI در «تصمیم آخر» دیده می‌شود: چه چیزی را عرضه می‌کنیم، با چه آستانه‌ای، و کجا انسان باید تأیید کند. هر قسمت یک artifact قابل‌اجرا دارد، و هر قسمت تیزر قسمت بعد را می‌سازد.

## اجرا با کلید API

قسمت‌هایی که «API» دارند به یک مدل زبانی واقعی نیاز دارند. همه از یک ابزار مشترک استفاده می‌کنند: [`tools/llm.py`](../../tools/llm.py).

کلید را در فایل `private/keys.env` بگذار (این پوشه در git نیست و منتشر نمی‌شود). یک خط کافی است:

```text
ANTHROPIC_API_KEY=...
```

به‌جای آن می‌شود `GEMINI_API_KEY=...` یا `OPENAI_API_KEY=...` گذاشت (برای درگاه‌های سازگار، `OPENAI_BASE_URL` و `HOMODYNE_MODEL` را هم در محیط تنظیم کن). `export` هم کار می‌کند، ولی فایل امن‌تر است: کلید وارد محیط هیچ پردازه‌ای نمی‌شود، پس کدی که ایجنت HMD-019 می‌نویسد نمی‌تواند آن را ببیند. برای HMD-019 اجرای کد ایجنت داخل Docker است؛ دستورش در README همان قسمت آمده.

```bash
python3 tools/llm.py check
```

بعد همان دستور `run` که در README هر قسمت آمده. هر جواب در پوشهٔ `artifact/runs/` ذخیره می‌شود؛ اجرای دوباره هزینه ندارد و همان عددها را می‌دهد. تا وقتی اجرای واقعی انجام نشده، قاب‌های نتیجه در متن برچسب `[RUN]` دارند و چیزی ادعا نمی‌کنند. دستور `report` هر قسمت بعد از اجرا، جمله‌های گفتاریِ همان قاب‌ها را با عدد واقعی چاپ می‌کند.
